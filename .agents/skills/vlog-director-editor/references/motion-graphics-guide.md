# งานกราฟิก (ขั้น 6)

กราฟิกจริงต้องสร้างจาก HTML, CSS, JS ชุดเดียวกับหน้า Preview เพื่อให้สิ่งที่ผู้ใช้เลือกตรงกับวิดีโอจริง

## ลำดับงาน

1. ล็อกจังหวะจาก Rough Cut ที่ผ่านแล้ว
2. ซับ 3 ชั้นตาม [variety-editing-grammar.md](./variety-editing-grammar.md)
3. กราฟิกตาม Style: Hero 1–3 จุดต่อตอน, ป้ายรอง, ลูกเล่นเล็ก
4. เอฟเฟกต์ภาพ: จอสั่นหลังกระแทก, Freeze Frame, Whip Transition, Speed Ramp
5. SFX ตรงเฟรมกระแทก ซ้อนเสียงเพื่อเพิ่มน้ำหนัก เช่น Whoosh แล้ว Hit
6. Mix สุดท้ายตาม [audio-production-guide.md](./audio-production-guide.md)
7. QA แล้วจึงส่งผู้ใช้

## มาตรฐานการออกแบบ

- ซับคำพูดสูงอย่างน้อย 44px บนจอ 1080p
- ข้อความไทยเรนเดอร์ผ่านเบราว์เซอร์ เพราะ PIL บนเครื่องนี้ไม่มี raqm สระและวรรณยุกต์จะเพี้ยน
- ใช้ฟอนต์จากไฟล์ใน `05_Shared_Assets/fonts/`
- ทุกกราฟิกต้องระบุเหตุการณ์ที่รับ
- ไม่วาง Hero ทับใบหน้า
- ก่อนส่งงานให้เช็ก "สิ่งที่ทำให้งานดูเป็น AI" ใน [style-library.md](./style-library.md)

## QA ก่อนส่ง

- ทุกไฟล์ในไทม์ไลน์มีจริง และเวลาไม่เกินความยาวคลิป
- บทพากย์ไม่ทับช่วงมุก
- ความเร็วอ่านซับเหมาะสม
- ไม่มีจอดำ ภาพค้างที่ไม่ตั้งใจ หรือเสียงเงียบผิดปกติ
- -14 LUFS และ True Peak ไม่เกิน -1 dB
- เปิดดูเฟรมของทุก Hero ว่าไม่บังหน้าและอ่านออกบนจอเล็ก

## สิ่งที่ส่งให้ผู้ใช้

คลิปเต็ม, รายการจุดเด่นพร้อมเวลา, ผล QA และรายการสิ่งที่เอเจนต์ตรวจเองไม่ได้
