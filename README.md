# Vlog Director & Editor

สกิลสำหรับ AI ที่ทำหน้าที่เป็นทีมตัดต่อ Vlog ท่องเที่ยวและครอบครัว คุณเลือกคลิป ตัดสินใจทิศทาง และอนุมัติงานทีละขั้น ส่วน AI วางแผนเรื่อง ตัดต่อ ใส่ซับและกราฟิก มิกซ์เสียง ตรวจคุณภาพ และเตรียมไฟล์อัปโหลด

ผลงานที่ได้คือคลิปสั้นพร้อมอัปโหลด:

- **แนวตั้ง** (Shorts, Reels, TikTok): ตั้งเป้าไม่เกิน 60 วินาที สูงสุด 90 วินาที
- **แนวนอน** (YouTube): ตั้งเป้า 1-2.5 นาที สูงสุด 3 นาที

## สิ่งที่ต้องมี

| สิ่งที่ต้องมี | ใช้ทำอะไร |
|---|---|
| AI ที่รันคำสั่งในเครื่องได้ เช่น Claude Code หรือ Codex | ตัวทำงานหลัก |
| Python 3.10 ขึ้นไป | รันสคริปต์ของสกิล |
| ffmpeg | ตัดต่อและเข้ารหัสวิดีโอ |
| Google Chrome | วาดกราฟิกและตัวหนังสือไทย |
| การ์ดจอ NVIDIA (ไม่บังคับ) | ทำให้ถอดเสียงและเรนเดอร์เร็วขึ้น |

ติดตั้งแพ็กเกจ Python ครั้งเดียว:

```bash
pip install numpy scipy opencv-python pillow playwright faster-whisper
```

## เริ่มใช้งานครั้งแรก

1. **ดาวน์โหลดสกิล** โคลน repo นี้ลงเป็นโฟลเดอร์โปรเจกต์ของทริปที่จะตัด หนึ่งทริปใช้หนึ่งโฟลเดอร์
   ```bash
   git clone https://github.com/nine-programmer/Vlog-Director-Editor.git ทริปของฉัน
   ```
2. **เปิดโฟลเดอร์นั้นด้วย AI** แล้วพิมพ์ `เริ่ม`
3. AI จะสร้างโฟลเดอร์งาน ดาวน์โหลดฟอนต์ สร้างเสียงประกอบ ตรวจว่าเครื่องพร้อม แล้วถามคุณ 5 เรื่อง: แนววิดีโอ รูปแบบ ช่วงของทริปที่สำคัญ คลิปตัวอย่างที่ชอบ และใครอยู่ในคลิป
4. **วางคลิปที่เลือกแล้ว** ลงใน `01_Raw_Footage/` แยกโฟลเดอร์ย่อยตามกล้อง แล้วพิมพ์ `สแกน`

คีย์ API ไม่จำเป็นต่อการตัดต่อ ถ้าอยากให้ AI สร้างภาพประกอบ เช่น สติกเกอร์ ให้คัดลอก `.env.example` เป็น `.env` แล้วใส่ `OPENAI_API_KEY` ไฟล์ `.env` จะไม่ถูกส่งขึ้น Git และ AI จะไม่เปิดอ่าน

## คำสั่งลัด

พิมพ์คำเดียวได้เลย หรือจะพิมพ์เป็นประโยคปกติก็ได้ เช่น "ตัดคลิปให้หน่อย"

| พิมพ์ | AI จะทำ |
|---|---|
| `เริ่ม` | ตั้งโปรเจกต์และถามบรีฟ |
| `สแกน` | ตรวจคุณภาพคลิปและถอดเสียงพูด |
| `ต่อ` | ทำงานต่อจากจุดที่ค้าง จนถึงจุดที่ต้องรอคุณ |
| `ถึงไหน` | สรุปสถานะทุกตอน และสิ่งที่รอคุณอยู่ |
| `ผ่าน` | อนุมัติสิ่งที่เพิ่งส่งให้ดู แล้วไปขั้นถัดไป |
| `แก้ ...` | แก้ตามที่บอก แล้วเรนเดอร์เวอร์ชันใหม่ เช่น `แก้ ช็อตเปิดยาวไป ตัดให้สั้นลง` |
| `ส่งมอบ` | เตรียมไฟล์อัปโหลดของตอนที่ผ่านแล้ว |

ปิดแชตแล้วกลับมาวันหลังได้ เปิดแชตใหม่แล้วพิมพ์ `ต่อ` หรือ `ถึงไหน` AI จะอ่านสถานะจากโฟลเดอร์โปรเจกต์เอง

## ขั้นตอนทั้งหมด

งานแบ่งเป็น 9 ขั้น AI จะหยุดรอคุณทุกขั้น เพราะการเปลี่ยนทิศทางหลังใส่กราฟิกแล้วเสียเวลามากกว่าเปลี่ยนตั้งแต่ต้น

| ขั้น | AI ทำ | คุณทำ |
|---|---|---|
| 0 ตั้งโปรเจกต์ | สร้างโฟลเดอร์ ถามบรีฟ | ตอบคำถาม วางคลิป |
| 1 สแกนฟุตเทจ | ตรวจความคม ความสว่าง ถอดเสียงพูด | ตัดสินใจว่าจะเอาคลิปที่ถูกแจ้งออกไหม |
| 2 เลือก Style | ทำหน้าเว็บให้ลอง 5 แนวบนคลิปจริง แล้วเรนเดอร์ตัวอย่าง 10-15 วินาที | เลือกแนว ฟอนต์ และโทนสี |
| 3 วางแผนเรื่อง | เสนอรายชื่อตอน แล้วเขียนแผนทุกช็อต | อนุมัติรายชื่อตอนและแผน |
| 4 เสียงพากย์และเพลง | เขียนใบสั่งงานเสียง | สร้างไฟล์แล้ววางตามที่ระบุ |
| 5 ตัดหยาบ | ตัดภาพและเสียงโดยยังไม่มีกราฟิก | ดูจังหวะการตัด |
| 6 กราฟิกและเรนเดอร์จริง | ใส่ซับและกราฟิก ตรวจคุณภาพอัตโนมัติ | แก้ซับที่ถอดผิด แล้วอนุมัติตอน |
| 7 รวมเป็นคลิปยาว | ถามก่อนเสมอ ไม่ทำเอง | ตอบว่าจะรวมหรือไม่ |
| 8 ส่งมอบ | ทำไฟล์อัปโหลด ภาพปก ชื่อคลิป คำอธิบาย | อัปโหลด |

ขั้น 3 วางแผนทุกตอนพร้อมกัน ส่วนขั้น 4-6 ทำทีละตอนจนจบ เพื่อไม่ให้ข้อผิดพลาดเดียวกันซ้ำในทุกตอน

### ขั้น 1: สแกนฟุตเทจ

AI ไม่เลือกคลิปแทนคุณ และไม่ลบไฟล์เอง มันรายงานเฉพาะปัญหาทางเทคนิค เช่น เบลอ มืด หรือสั้นเกินไป รายงานอยู่ที่ `02_Scan_Reports/scan_report.md`

ชื่อไฟล์คลิปต้องไม่ซ้ำกัน แม้อยู่คนละโฟลเดอร์ ถ้าซ้ำ AI จะขอให้เปลี่ยนชื่อ

### ขั้น 2: เลือก Style

AI จะส่งไฟล์ `03_Style/preview/index.html` ให้เปิดใน Chrome ในหน้านั้นสลับแนว ช่วงคลิป รูปแบบ และฟอนต์ได้ สิ่งที่เห็นในหน้านี้ใช้โค้ดชุดเดียวกับตอนเรนเดอร์จริง

| แนว | เหมาะกับ | ข้อควรรู้ |
|---|---|---|
| สมุดทริป (scrapbook) | ทริปหลายสถานที่ ของกิน ความทรงจำครอบครัว | มุกแรงๆ จะนุ่มลง |
| วาไรตี้จิมัก (variety) | มุกจากคำพูดและรีแอ็กชัน | ถ้าใส่กราฟิกทุกวินาทีจะเหมือนบังคับให้ขำ |
| คอมิกบึ้ม (comic) | จังหวะพีค ฮากระแทก | แรงมาก เหมาะกับตอนสั้นไม่เกิน 60 วินาที |
| สมุดนักสำรวจ (journal) | วิว สถานที่ | มุกตลกจะไม่ระเบิด และอ่านยากบนท้องฟ้าสว่าง |
| แสงเย็น (soft) | ความสุขของคน ช็อตอบอุ่น | ถ้าใช้ทั้งเรื่องจะขาดความสนุก และอ่านยากบนภาพสว่าง |

หนึ่งตอนใช้ได้หนึ่งแนว ถ้าอยากได้หลายแนว ให้ใช้คนละแนวต่อตอน

### ขั้น 4: เสียงพากย์และเพลง

คุณเป็นคนสร้างเสียงเอง AI จะเขียนใบสั่งงานไว้ที่ `04_Episodes/EPxx_ชื่อตอน/audio_order.md` ในนั้นบอกบทพากย์ทุกท่อน ข้อความ Style เพลง ชื่อไฟล์ และโฟลเดอร์ที่ต้องวาง

- **เสียงพากย์:** สร้างที่ [Google AI Studio](https://aistudio.google.com) โหมดสร้างเสียงพูด
- **เพลง:** สร้างที่ [Suno](https://suno.com) เข้าโหมด Advanced เว้นช่องเนื้อเพลงว่าง แล้วใส่เฉพาะข้อความในช่อง Style จะได้เพลงไม่มีเสียงร้อง

ตั้งชื่อไฟล์ให้ตรงกับใบสั่งทุกตัวอักษร วางเสร็จแล้วพิมพ์ `ต่อ`

### ขั้น 5-6: ตรวจงาน

- **ตัดหยาบ** อยู่ที่ `04_Episodes/EPxx_ชื่อตอน/renders/EPxx_Rough_v01.mp4` ดูแค่ลำดับช็อตและจังหวะ ยังไม่มีกราฟิก
- **ตรวจซับ** AI จะส่ง `captions.md` ให้ แก้เฉพาะคอลัมน์ "ข้อความ" ถ้าอยากลบซับอันไหน ให้พิมพ์คำว่า `ลบ` แทนข้อความ
- **งานจริง** อยู่ที่ `renders/EPxx_Full_v01.mp4` พร้อมรายงานตรวจคุณภาพในโฟลเดอร์ `qa/`

ทุกครั้งที่แก้ จะได้ไฟล์เวอร์ชันใหม่ (`_v02`, `_v03`) ไฟล์เก่าไม่ถูกเขียนทับ

AI ฟังเสียงไม่ได้และตัดสินความตลกไม่ได้ สิ่งที่คุณต้องตรวจเองทุกตอนคือ ความดังของเพลงเทียบกับเสียงพูด การออกเสียงของเสียงพากย์ จังหวะของมุก และความลื่นของการซูมกับการเร่งความเร็ว

## ลูกเล่นที่สั่งได้

บอก AI เป็นภาษาคนได้เลย เช่น "ช็อตมุกหลักขอเต็มจอ แล้วหยุดเพลงก่อนพูด"

| ลูกเล่น | ผลที่เห็น |
|---|---|
| ซูมกระแทก | ภาพพุ่งเข้าตรงคำมุกแล้วเด้งกลับ |
| ซูมหรือแพนช้า | ภาพค่อยๆ ดันเข้า แพน หรือถอยออกตลอดช็อต |
| ช็อตเต็มจอ (แนวตั้ง) | ช็อตนั้นเต็มจอ แถบบนล่างหายไปชั่วคราว |
| เร่งแล้วผ่อน | เร่งช่วงเดินทาง แล้วผ่อนเป็นปกติก่อนถึงจังหวะสำคัญ |
| ภาพช้าย้อนดู | เล่นจังหวะเด็ดซ้ำแบบช้าและซูมใกล้ |
| หยุดภาพ | ค้างเฟรมเพื่อแนะนำคนหรือโชว์สีหน้า |
| เพลงหยุดก่อนมุก | เพลงเงียบครู่เดียวให้ประโยคเด่น แล้วกลับมา |
| ปรับโทนสี | 7 แบบ เช่น อุ่น เย็น ฟิล์ม สด ขาวดำ |
| กราฟิก 13 ชนิด | ซับ คำกระแทก คอมเมนต์ ป้าย ตารางคะแนน ป้ายชื่อ ตราประทับ สติกเกอร์ ลูกศร วงกลม ทรานซิชัน |
| เน้นคำในซับ | คำสำคัญเปลี่ยนเป็นสีเน้นของแนวนั้น |

ช็อตเต็มจอจากคลิป 1080p จะเบลอ เพราะต้องขยายเกือบสองเท่า ถ้าอยากใช้ลูกเล่นนี้บ่อย ให้ถ่ายเป็น 4K

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| AI ไม่ใช้สกิล | พิมพ์ `เริ่ม` หรือ "ใช้สกิล vlog-director-editor" ใน Claude Code พิมพ์ `/vlog-director-editor` ได้ |
| ไม่รู้ว่าเครื่องขาดอะไร | บอก AI ว่า "ตรวจเครื่อง" มันจะรันตัวตรวจและบอกสิ่งที่ต้องติดตั้ง |
| ถอดเสียงช้ามาก | เครื่องไม่มีการ์ดจอ NVIDIA จึงใช้ CPU ซึ่งช้ากว่าหลายเท่า ต้องรอ หรือวางเฉพาะคลิปที่จะใช้จริงเพื่อลดงาน |
| ซับผิดเยอะ | เป็นปกติของการถอดเสียงภาษาไทย แก้ในขั้นตรวจซับ |
| ซับตัวเล็กผิดปกติ | ข้อความยาวเกินบรรทัด บอก AI ให้แบ่งเป็นสองซับ |
| เพลงเงียบก่อนจบคลิป | ไฟล์เพลงสั้นกว่าช่วงที่ใช้ ระบบไม่วนเพลงให้ ต้องสร้างเพลงที่ยาวขึ้น |
| อยากเริ่มทริปใหม่ | โคลน repo ลงโฟลเดอร์ใหม่ แล้วพิมพ์ `เริ่ม` |

## สำหรับผู้ที่อยากปรับสกิล

ตัวสกิลอยู่ที่ `.agents/skills/vlog-director-editor/`

- `SKILL.md`: ขั้นตอนหลักที่ AI ทำตาม
- `references/`: กฎการตัดต่อ คู่มือไทม์ไลน์ คลัง Style คู่มือกราฟิกและเสียง
- `scripts/`: สคริปต์สแกน เรนเดอร์ ตรวจคุณภาพ และส่งมอบ
- `assets/styles/`: ตัววาดกราฟิกและไฟล์ของแต่ละ Style วิธีเพิ่มแนวใหม่อยู่ท้ายไฟล์ `references/style-library.md`
